# V1
A cool CLI interface that can (will be able to) tell you cool space facts. In this folder is the `.py` Python source files. 

To run this you will need to have `rich` and `requests` installed. A compiled `.exe` is also included for those who have a Windows machine and just want to run the program. 

This program is going to include many tools for stuff including:
* **Planned commands:** `locate n astroid` (*n* for nearest)
* **Planned themes:** The current theme is called *101 shades of green*
* **Planned NASA API Key Entering**
